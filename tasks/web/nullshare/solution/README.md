1. Зарегистрироваться и войти в систему, осмотреться, зайти на страницу изображения.
2. Увидеть используемый идентификатор, узнать что такое UUID (по подсказке) или вспомнить. 
3. Отправить запрос для получения изображения с ID 00000000-0000-0000-0000-000000000000
4. Система вернет приватное изображение администратора, содержащее флаг

Пример запроса:
```
GET http://nullshare.tasks.vrnctf.ru/images/00000000-0000-0000-0000-000000000000
```
