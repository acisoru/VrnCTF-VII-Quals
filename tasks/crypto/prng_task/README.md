**Category:** Crypto

**Description:**

Использовал он для сего дела не простые методы шифрования, а хитроумный механизм «рандомизации»,

а для забавы математической. Теперь же нам надлежит указ расшифровать,

Сможете ли вы разгадать шифр Петра, основанный на предсказуемом генераторе 
псевдослучайных чисел, и прочесть его тайное послание?
