# Решение

Для того что бы решить задачу, было необходимо произвести статический анализ бинарного файла. В бинарнике вы бы увидели алгоритм генерации и сверки ключа, по входным данным. Нужно было восстановить алгоритм генерации ключа, переписать псевдокод, предоставляемый декомпилятором, на любой удобный язык программирования. Сгенерировав ключ по любым входным данным, вам нужно было обратиться к сайту, указанному в блоке задачи. Там вы бы ввели полученные данные и получили фраг.
