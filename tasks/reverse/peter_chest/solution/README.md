# Решение

Задача могла быть решена при помощи статического анализа. Для запутывания логики программы был использован прием, при котором некий исполняемый код располагается в секции .init_array 
После анализа располагающегося в этой секции кода, вы бы заметили, что при запуске программы он устанавливает в прологе функции random() патч, который всегда возвращает -1, тем самым, ломая логику работы программы. В дальнейшем, проведя анализ бинарника, вы бы могли заметить функцию, которая выполняла операцию XOR над неким массивом байт, копировала этот массив в память, делала память исполняемой и вызывала получившийся шелл. Вам нужно было увидеть, что операция XOR происходила как раз с использованием функции random(), которая, как мы уже знаем до этого, всегда возвращает при исполнении -1. Нужно было вытащить шеллкод, поксорить его на -1 и запустить, тогда вам бы вывелся флаг.
